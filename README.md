# Proyecto académico personal

Copia independiente que conserva el trabajo personal realizado hasta el 30 de octubre de 2026, incluidas las mejoras de productos personalizados, búsqueda y filtros del dashboard.

## Contenido

- `ProjectApp/`: aplicación Expo con los cambios más recientes.
- `Parcial_1_Moviles/`: aplicación del parcial conservada junto al proyecto.
- `Reporte_Consumo_Servicio_Producto.html` y `.pdf`: reportes del proyecto.

## Ejecutar la aplicación

```bash
cd ProjectApp
npm install
npm run web
```

Consulta `ProjectApp/README.md` para otras opciones de ejecución.

## Origen

El proyecto parte de una base académica compartida. Esta copia conserva los archivos y comienza un historial Git independiente; no importa los commits ni el historial de contribuciones del repositorio anterior.
